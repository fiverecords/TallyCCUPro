## TallyCCU Pro v3.8.2 — Safe Mode without the SD card, serial configurator and web fixes

Fixes found while using v3.8.1 on real hardware. Everything in [v3.8](https://github.com/fiverecords/TallyCCUPro/releases/tag/v3.8) and [v3.8.1](https://github.com/fiverecords/TallyCCUPro/releases/tag/v3.8.1) is included.

**Compatible with the current Bitfocus Companion module (v3.1.0) without any change to the module** — the camera control protocol (port 8098 and the HTTP API) is unchanged, and CI drives the official module against this firmware.

---

### 🔴 Fixes

- **Serial configurator: the first command after connecting was lost.** Since v3.8 the configurator connects without restarting the Arduino. Opening the USB port can deliver a garbage byte to the board, which was glued to the first command, so *Get Config* did nothing until another command (for example *Help*) was sent. The configurator now sends a newline before each command, and the firmware ignores control and non-ASCII bytes on the serial console.
- **Safe Mode page without the SD card.** In Safe Mode, when the SD card is missing or cannot be read, or `safemode.html` is not on it, the address of the board now shows a built-in page with the reason, the last reset, the firmware version and the **Restart in normal mode** button. v3.8 announced it, but v3.8 and v3.8.1 answered `404` or `503` there.

### 🟡 Improvements

- **The web page retries a request that is refused at once.** With nearly every network connection of the Arduino in use (vMix, Companion, two pages with the real-time sync, a page reloading), a request could be refused for a moment. *Reset to Defaults* then stopped halfway and left the rest of the values unknown (`?`), and *Load* or *Save* preset failed. Error messages now stay on screen for 8 s.
- **Old configurator removed from the repository.** The `TallyCCU_Configurator.exe` that was in `tools/` was a V3.6-era build: it restarted the Arduino on connect and *Get Config* did not fill the fields. Use the `.exe` attached to this release.

### 🛠 For developers

- New manual workflow *Configurator exe* (*Actions* → *Configurator exe* → *Run workflow*): builds the configurator `.exe` from any branch, like the release does, without making a release.
- New emulator scenarios: `sm` (built-in Safe Mode page) and `ser` (garbage bytes on the serial console), both in the fast set that CI runs.

---

### Upgrade Instructions

1. Flash the Arduino sketch from the **`firmware/TallyCCUPro/`** folder.
2. Copy `index.html` and `index.html.gz` from the zip's `sdcard/` folder to your SD card (replace existing): it is the only page that changed since v3.8.1. Coming from v3.8 or older, copy all the `.html` and `.gz` files.
3. Use the **`TallyCCU_Configurator.exe` attached to this release** (Windows SmartScreen may warn the first time: the `.exe` is not code-signed).
4. Power cycle the device.

Your network settings, tally map and presets are kept. Coming from v3.7.1 or older, read the v3.8 upgrade notes too (firmware and SD files must be updated together; own scripts need the `X-TallyCCU: 1` header).

The firmware version shows as **3.8.2** in the serial monitor (`status`), the serial configurator and `/safemode-status`.
