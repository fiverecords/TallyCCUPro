## TallyCCU Pro v3.8.1 — Hotfix: builds with the official Blackmagic library

v3.8 did not compile in the Arduino IDE with the official Blackmagic `BMDSDIControl` library. This release fixes that; **everything else is v3.8** (see the [v3.8 release notes](https://github.com/fiverecords/TallyCCUPro/releases/tag/v3.8) for the full list of changes from the code audit).

**Same behaviour as v3.8 on the cameras, tally and Companion:** built against the same library, v3.8 and v3.8.1 produce the same machine code (apart from the version number). Still compatible with the current Bitfocus Companion module (v3.1.0) without any change to the module.

---

### 🔴 Fixes

- **v3.8 did not compile** with the official library:
  `no matching function for call to 'BMD::I2CPhysical<BMD::SDICameraControl>::writeCommandInt8(..., const int8_t [2])'` (and the same for `writeCommandInt16`, `writeCommandInt32` and `writeCommandFixed16`). The library takes list values (for example lift/gamma/gain or color correction) as non-const arrays, and v3.8 passed const ones. The compile-only stub used by the automatic builds (CI) accepted both, so the error was not caught. The firmware now passes non-const arrays, and the CI stub copies the official library's declarations, so a mismatch like this one now fails CI. The firmware was also built against the real library code.
- **SD Card Manager listed the `.gz` copies of the system pages** (`index.html.gz`, `tally.html.gz`...) when the board still ran firmware older than v3.8. The page now hides the system pages and their `.gz` by itself (v3.8 firmware already hid them).

### 🛠 For developers

- `tests/ci/build_avr.sh` builds against a real `BMDSDIControl` library with `BMD_DIR=<library folder>` (for example `BMD_DIR=~/Arduino/libraries/BMDSDIControl tests/ci/build_avr.sh`).

---

### Upgrade Instructions

1. Flash the Arduino sketch from the **`firmware/TallyCCUPro/`** folder (it was `Arduino/` before v3.8).
2. Copy the HTML files from `sdcard/` to your SD card (replace existing), and the `.gz` files included in the zip next to them (recommended: pages load about 5x faster). Only `sdcard.html` changed since v3.8, so replace `sdcard.html` **and** `sdcard.html.gz` together.
3. Power cycle the device.

Coming from v3.7.1 or older: update the firmware and the SD card files together, as described in the v3.8 notes. Your network settings, tally map and presets are kept.

The firmware version shows as **3.8.1** in the serial monitor (`status`), the serial configurator and `/safemode-status`.
