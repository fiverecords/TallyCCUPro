📷 Tally Mapping (vMix input → BMD camera)

Each of the 10 tally slots links one vMix input to one Blackmagic camera. vMix Input is the input number in vMix (1-63), and BMD Cam ID is the camera identifier in the Blackmagic SDI system (1-8). Slot numbers are not camera numbers: any slot can drive any camera. A slot with both fields empty is unused: Clear (or saving it empty) removes a saved mapping. One input can light several cameras, and several inputs one camera.
